Privacy policy

Dimaag Tez Hindi Uploader is the publishing tool of the Dimaag Tez Hindi YouTube channel. It is used only by the owner of that channel.

What the tool accesses

With the channel owner's permission, the tool uses YouTube API Services to:

  • upload videos to the owner's own channel and set their titles, descriptions, tags, thumbnails, playlists and publish times;
  • read statistics of the videos it uploaded (views, likes, comments and watch-time reports from YouTube Analytics).

It does not access any other person's Google account or YouTube data.

What the tool stores

The sign-in token is kept in the owner's private, access-controlled storage. The tool keeps a list of the videos it uploaded and their statistics so it can plan future videos. It does not collect or store personal information about viewers or any other person.

How the data is used and shared

The data is used only to publish and improve the channel's own videos. It is not sold, not used for advertising, and not shared with third parties.

Retention and deletion

Video statistics are kept while the channel is active. The owner can delete the stored data at any time and can revoke the tool's access at myaccount.google.com/permissions, after which the tool can no longer reach the account.

Google and YouTube policies

The tool uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. See also the Google Privacy Policy. The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be sent through the channel's About page: youtube.com/@DimaagTezHindi.
